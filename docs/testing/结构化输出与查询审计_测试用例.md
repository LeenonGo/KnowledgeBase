## 三、API 接口测试（curl）

### TC-10: 带 output_format 的查询

```bash
# 表格格式
curl -N -X POST http://localhost:8000/api/sql/query \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"question": "各品类销售额", "output_format": "table"}'

# JSON 格式
curl -N -X POST http://localhost:8000/api/sql/query \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"question": "各品类销售额", "output_format": "json"}'

# 报告格式
curl -N -X POST http://localhost:8000/api/sql/query \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"question": "各品类销售额", "output_format": "report"}'
```

预期：SSE 流返回 `event: sql` → `event: result` → `event: analysis` → `event: done`，analysis 事件 data 中包含 `output_format` 字段。

### TC-11: 查询审计日志 API

```bash
# 获取审计日志
curl http://localhost:8000/api/sql/audit-logs \
  -H "Authorization: Bearer YOUR_TOKEN"

# 按格式筛选
curl "http://localhost:8000/api/sql/audit-logs?output_format=json" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 按状态筛选
curl "http://localhost:8000/api/sql/audit-logs?status=error" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 分页
curl "http://localhost:8000/api/sql/audit-logs?page=2&page_size=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

预期：返回 `{ total, page, page_size, items: [...] }`，items 中每条包含 question / generated_sql / output_format / row_count / elapsed_ms / total_ms / error / status / created_at。

## 四、测试注意事项

1. **Embedding 额度**：确保 DashScope 有足够额度，SQL 查询本身不消耗 embedding，但不要同时触发知识库重建
2. **MySQL 连接**：确保 `SQL_AGENT_DB_URL` 环境变量配置正确，ecommerce_demo 数据库有数据
3. **LLM 额度**：每次 SQL 查询会消耗 2-4 次 LLM 调用（生成 SQL + 分析总结），注意 token 用量
4. **浏览器兼容**：建议用 Chrome/Edge 测试，SSE 和 Clipboard API 可能在旧版浏览器不支持
