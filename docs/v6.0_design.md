## 二、v6.0 Skills 插件化架构

### 2.1 设计目标

1. **模块化**：每个 Skill 是独立的能力单元，可单独开发、测试、部署
2. **可插拔**：管理员可动态启用/禁用 Skill，无需改代码
3. **可扩展**：支持用户自定义 Skill（配置化，不写代码）
4. **可组合**：多个 Skill 可串联执行，形成工作流

### 2.2 架构设计

```
┌─────────────────────────────────────────────────┐
│                   Agent 引擎                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────┐ │
│  │  Planner    │  │  Executor   │  │ Memory  │ │
│  │  (规划器)    │  │  (执行器)   │  │ (记忆)  │ │
│  └──────┬──────┘  └──────┬──────┘  └─────────┘ │
│         │                │                       │
│  ┌──────▼────────────────▼──────┐               │
│  │       Skill Registry         │               │
│  │       (技能注册中心)          │               │
│  └──────┬────────────────┬──────┘               │
│         │                │                       │
│  ┌──────▼──────┐  ┌──────▼──────┐               │
│  │ Built-in    │  │ Custom      │               │
│  │ Skills      │  │ Skills      │               │
│  └─────────────┘  └─────────────┘               │
└─────────────────────────────────────────────────┘
```

### 2.3 Skill 数据模型

```python
class Skill(Base):
    """技能定义"""
    id = Column(String(32), primary_key=True)
    name = Column(String(100), unique=True)          # 唯一标识
    display_name = Column(String(100))                # 显示名称
    description = Column(Text)                        # 功能描述
    category = Column(String(50))                     # 分类：retrieval/analysis/generation/utility
    version = Column(String(20))                      # 版本号
    author = Column(String(100))                      # 作者
    
    # Skill 配置（JSON Schema）
    parameters_schema = Column(JSON)                  # 参数定义
    return_schema = Column(JSON)                      # 返回值定义
    
    # 执行配置
    handler_type = Column(String(20))                 # python / http / prompt
    handler_config = Column(JSON)                     # 执行逻辑配置
    
    # 权限 & 限制
    required_permissions = Column(JSON)               # 所需权限
    rate_limit = Column(Integer, default=100)         # 每分钟调用上限
    timeout_seconds = Column(Integer, default=30)     # 超时时间
    
    # 状态
    is_enabled = Column(Boolean, default=True)
    is_builtin = Column(Boolean, default=False)
    usage_count = Column(Integer, default=0)          # 调用次数统计
    avg_latency_ms = Column(Float)                    # 平均延迟
    
    created_at = Column(DateTime, default=func.now())
    updated_at = Column(DateTime, onupdate=func.now())
```

## 三、v6.1 Eval Harness 评测体系

### 3.1 设计目标

1. **自动化**：每次 Prompt/模型变更后自动触发评测
2. **可回归**：历史评测结果可对比，防止效果退化
3. **多维度**：准确性、相关性、延迟、成本、安全性
4. **可视化**：评测报告自动生成，支持趋势分析

### 3.2 架构设计

```
┌─────────────────────────────────────────────────┐
│                Eval Harness                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────┐ │
│  │  Datasets   │  │  Runner     │  │ Reports │ │
│  │  (数据集)    │  │  (执行器)   │  │ (报告)  │ │
│  └──────┬──────┘  └──────┬──────┘  └─────────┘ │
│         │                │                       │
│  ┌──────▼────────────────▼──────┐               │
│  │         Metrics Engine       │               │
│  │         (指标引擎)            │               │
│  └──────┬────────────────┬──────┘               │
│         │                │                       │
│  ┌──────▼──────┐  ┌──────▼──────┐               │
│  │  LLM-as-    │  │  Traditional│               │
│  │  Judge      │  │  Metrics    │               │
│  └─────────────┘  └─────────────┘               │
└─────────────────────────────────────────────────┘
```

### 3.3 评测指标体系

| 维度 | 指标 | 计算方式 | 权重 |
|------|------|----------|------|
| **准确性** | Answer Correctness | LLM-as-Judge 评分 (1-5) | 30% |
| **相关性** | Answer Relevance | 回答与问题的相关度 | 25% |
| **检索质量** | Context Precision | 检索结果中相关文档占比 | 20% |
| **检索质量** | Context Recall | 相关文档被检索到的比例 | 10% |
| **延迟** | Response Latency | 端到端响应时间 | 10% |
| **幻觉** | Hallucination Rate | 回答中无依据内容占比 | 5% |

### 3.4 评测数据集管理

```python
class EvalDataset(Base):
    """评测数据集"""
    id = Column(String(32), primary_key=True)
    name = Column(String(100))
    description = Column(Text)
    category = Column(String(50))           # general/domain/specific
    
class EvalQuestion(Base):
    """评测问题"""
    id = Column(String(32), primary_key=True)
    dataset_id = Column(String(32), ForeignKey('eval_dataset.id'))
    question = Column(Text, nullable=False)
    expected_answer = Column(Text)          # 标准答案（可选）
    expected_sources = Column(JSON)         # 期望的来源文档
    difficulty = Column(String(20))         # easy/medium/hard
    tags = Column(JSON)                     # 标签
    
class EvalRun(Base):
    """评测运行记录"""
    id = Column(String(32), primary_key=True)
    dataset_id = Column(String(32))
    model_version = Column(String(50))      # 模型版本
    prompt_version = Column(String(50))     # Prompt 版本
    config = Column(JSON)                   # 评测配置
    status = Column(String(20))             # running/completed/failed
    summary = Column(JSON)                  # 汇总结果
    
class EvalResult(Base):
    """单条评测结果"""
    id = Column(String(32), primary_key=True)
    run_id = Column(String(32))
    question_id = Column(String(32))
    answer = Column(Text)                   # 实际回答
    latency_ms = Column(Integer)
    metrics = Column(JSON)                  # 各维度得分
    passed = Column(Boolean)                # 是否通过阈值
```

### 3.5 评测流程

```
1. 选择数据集
   ↓
2. 配置评测参数（模型、Prompt 版本、阈值）
   ↓
3. 批量执行（并行调用 Agent）
   ↓
4. 指标计算（LLM-as-Judge + 传统指标）
   ↓
5. 生成评测报告
   ↓
6. 与历史结果对比（趋势分析）
   ↓
7. 输出改进建议
```
